## Инструкция по запуску:
1) проверьте установку всего програмного пакета
2) проверьте установку питона, при необходимости установите через ...(нужно скопировать команду из твоего powershell)
3) проверьте установку или устонавите модули fastaoi и uvicorn (
    python -m pip install --upgrade pip
    python -m pip install fastapi uvicorn python-multipart
)
4) запустите файл main
5) перейдите на сайт http://127.0.0.1:8000
6) закройте программу, перейдя в командную строку и нажав CTRL+C
